ROCK PAPER SCISSORS GAME

A simple browser game where the player competes against the computer in a classic Rock Paper Scissors match.

PROJECT OVERVIEW

The game includes:
- Three clickable choices: Rock, Paper, and Scissors
- Random computer selection on every turn
- Real-time score tracking for both the player and the computer
- Dynamic result message after each round
- Clean, modern UI with responsive styling

TECH STACK

- HTML5
- CSS3
- JavaScript (Vanilla JS)

FEATURES

- Player vs computer gameplay
- Scoreboard for My Score and Computer Score
- Instant round result updates
- Visual feedback for winning and losing outcomes
- Lightweight and easy to run locally

HOW TO RUN

1. Open the project folder in your code editor.
2. Make sure all files are present in the same directory.
3. Open index.html in a browser.
4. Click one of the game icons to start playing.

GAME RULES

- Rock beats Scissors
- Paper beats Rock
- Scissors beats Paper
- Same selections result in a tie

PLAYING GUIDE

- Select Rock, Paper, or Scissors.
- The computer makes a random move.
- The game compares the choices and updates the scoreboard.
- Continue playing to increase your score.
